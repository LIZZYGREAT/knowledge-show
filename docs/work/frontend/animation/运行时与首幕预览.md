# 动画运行时 P0 与 PN 首幕

当前仅实现《动画层与工作台接入执行方案》的 P0。输入为 `docs/work/backend/script/trials/case2-pn-v2/production-script.json` 的 `PS001-r1 / S01`，0–15000ms；它是固定历史试验脚本，未调用上游生成服务。舞台使用 1600×900 逻辑坐标，不改原脚本、165s 全片时长或公共 Schema。尚未生成完整 AnimationManifest、接入工作台、自动修订或导出视频。

## 创意与美术

同一个磨砂结本体、等长金属引线、红蓝粒子群和同一台仪表承担主动作。EV01 先展示粒子穿行与大幅偏转；EV02 按脚本在 6s 开始整体旋转接法，粒子抵达界面后回弹，保留少量穿行和微小仪表偏转；EV03 从 10s 开始将同一个对象的两种状态并排对照，缓慢推近。T01 严格按原脚本 9.5–11.4s 显示。接触面保持柔化，不揭示势垒、电场或载流子机制。

`precisionScience` 描述独立视频艺术语言：深蓝空间、磨砂陶瓷、拉丝金属、柔和侧光、低对比刻度。视频在 Shadow DOM 内渲染，不导入网页 theme、不读取 `--ks-*`；包围盒高亮为外部叠加层，不进入场景 SVG。四种风格选择属于 P2，本轮仅实现第一种。

## 本地运行

```bash
cd frontend
npm run dev
```

打开 `http://127.0.0.1:5173/animation-preview.html`。支持播放/暂停、连续拖动、0/6/10/15s 定位和对象边界检查。它是独立研发入口，不替代正式创作页或工作台。`npm run build` 同时编译主应用与预览入口。

## Runtime 与 P1 接口

- `SceneDefinition.mount(host)` 创建独立场景；`SceneHandle.seek(localTimeMs)` 同步重建画面，查询当前逻辑对象的归一化边界；`destroy()` 移除 SVG 并 kill GSAP Timeline。
- `AnimationPlayer(host, definition)` 目前只接受一个场景。提供 `play/pause/seekAndWaitForFrame/getCurrentTimeMs/getSelectableElements/getElementBounds/destroy` 以及播放订阅。
- Seek 在目标画面写入后等待浏览器帧；连续请求以序号拒绝过期结果（`AbortError`）。恢复播放或销毁也使未完成 Seek 失效，调用方应忽略这类取消。
- 时间统一使用毫秒；GSAP 边界通过 Runtime 的 `timelineSeconds` 转换为秒。场景事件节点来自原脚本，不读取网页动画时钟。
- 注册稳定 ID：`EL_S01_JUNCTION`、`EL_S01_CARRIERS`、`EL_S01_METER`、`T01`。同一对象的并排实例共享逻辑 ID，bbox 是其可见实例的联合外包矩形；不可见、未知或不在内容区域内时返回 null。
- SVG 填满 16:9 舞台；元件边界相对于实际内容矩形归一化，内部变换、旋转、镜头推进及网页缩放由实际 DOM 几何计算。P1 在带 letterbox 的工作台中应先计算内容矩形，再按该矩形绘制高亮。
- P1 需要在现有接口外补精确 Manifest 版本与资源解析、多场景全局时间映射、S02、轨道适配；P0 没有伪造这些资源或发布状态。

构建、现有 10 项逻辑测试、19 项 Chromium 浏览器测试（其中 4 项播放器测试）通过。覆盖不同路径 Seek 到 6.2s 的同帧 SVG、稳定对象身份、字幕可见区间、0/6/10/15s 几何、375/1280/1920px、样式隔离、连续 Seek 取消、播放暂停与销毁。公共契约校验通过（22 个负例及历史 Manifest 兼容）；未调用 API。

实际关键帧和完整播放录屏存放在本机 `/tmp/knowledge-show-animation-p0/`，不是正式产物或提交的素材。首轮截图修复了金属引线渐变与翻转时的裁切；后续美术验收仍需检查 PN 结构的辨识度和转场镜头质量。没有配音或音效，原脚本 audio_intent 尚未实现。

编码时参考已安装的 Motion Design、GSAP Core、Timeline、React Skills；这些只指导设计与实现，不是运行时调用的服务。
