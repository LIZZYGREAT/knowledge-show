# 动画运行时、工作台与成片验收

当前实现覆盖执行方案 P0–P4：独立风格、确定性场景运行时、真实时间轴选择、定向修订、检查后发布与同源 MP4 导出。PN v2 历史脚本作为明确的固定验收样本，已完成七幕、165000ms；正式入口消费项目当前的精确 ProductionScript，不将固定样片当作其他项目成果。公共 Schema 未改变。

## 创作与生成规约

先解释脚本如何被看见：确定持续存在的知识对象、前置状态、因果变化和观看焦点，再选择材质、空间、文字与运动。风格档案仅提供艺术语言，不预设场景构图。保留脚本 timed_text 的原文、ID、显示时间和 anchor 事件时刻；知识结论、极性或叙事时间修改交回上游。

四份内部档案位于 `frontend/src/animation/styles/profiles/profiles.json`：精密科学、纸艺编辑、现代图形、叙事拼贴。它们由同一播放器消费，不读取网页主题。除色彩外，纸材纹理、边角、图形线重、字体与仪表材质有所区别；支持 auto、自定义完整档案和用户美术偏好。PN 主体使用红蓝载流子、固定晶格离子、实体结、势垒地形、电场与仪表建立解释关系，不用任意霓虹粒子代替知识对象。

编码参考已安装的 Motion Design、GSAP Core / Timeline / React Skills；它们仅指导创作，不在浏览器读取。项目内的实践规则：

- 连续运动由知识事件驱动；关键转变前给出可观察的起始姿态，不以标题轮播承担主体内容。
- 对象身份跨镜头稳定。固定离子不随载流子流动；内建场从 N 指向 P；反向保留微小流动，断电后不出现持续外电流；半波整流截去负半周。
- 关键姿态检查主体轮廓、文字避让、遮挡与空间关系；动态检查因果先后、轨迹、节奏与连续性。实际画面审核不能由 JSON 校验替代。

`backend/src/animation/director.py` 将精确场景、知识限制与 Profile 交给注入的模型客户端。为控制执行边界，模型输出受验证的 SVG 对象及关键帧数据，由已编译的 VectorScene 解释；不运行模型 JS/HTML，不给渲染子进程模型密钥。新主题可以创建新的路径、对象与构图，不查整幕模板列表。PN 离线实现仅在脚本 scenes 与历史固定样本完全相等时启用。

## 本地运行与离线验收

```bash
cd frontend
npm ci
npx playwright install chromium
npm run build
npm run dev
```

系统还需 Chromium 运行库、中文字体、FFmpeg 和 ffprobe。后两者可在 PATH 中提供，或配置 `ANIMATION_FFMPEG` / `ANIMATION_FFPROBE` 为绝对路径。WSL 验证使用 `/tmp` 解包的库与字体，通过 `LD_LIBRARY_PATH` / `FONTCONFIG_FILE` 注入；这些是本机环境，不属于仓库资源。

在另一终端启动 API：

```bash
PYTHONPATH=backend/src .venv/bin/python -m uvicorn api.app:app --host 127.0.0.1 --port 8000
```

正式创作页在脚本发布后显式发起动画任务，刷新可恢复进度；实际播放器检查通过、资源可读取后开放工作台。失败不替换旧成果。离线检查可打开 `/workbench.html?demo=pn`；它明确显示固定样片，不提交正式修订或伪造项目成果。

完整无模型验收可先导入历史样本到正常项目存储：

```bash
PYTHONPATH=backend/src .venv/bin/python -m animation.seed
```

该命令创建独立样本项目，返回 project_id 和 revision。用该 revision 调用 `POST /api/projects/{id}/animations`（`style_id: precision-science`），轮询动画 job，完成后打开预览回执中的工作台 URL。选择 S02 载流子，输入“这里的粒子运动减慢一点”，提交后会产生新 Manifest，仅 S02 的资源引用改变；版本回退可恢复旧版。首次 PN 发布和减速不需要 API Key；其他新主题或模型美术改写需要本次凭证。

导出可在工作台点击“导出视频”，或直接使用同一个逐帧入口：

```bash
node frontend/scripts/render-video.mjs --bundle /absolute/path/to/checked-bundle.json --output /absolute/path/to/export
```

默认 24fps、1280×720、H.264、yuv420p。进度记录实际帧数；浏览器、编码器或 ffprobe 失败时不开放下载。当前成片无音轨；配音、音乐与音效未接入，不声称已经实现 audio_intent。

## Runtime 与工作台边界

- `AnimationPlayer(host, definition)` 是唯一播放系统。`createSequence(bundle)` 验证版本及完整覆盖，按全片时间装配场景、映射局部毫秒，并销毁上个场景。GSAP 秒数转换集中在 `runtime/time.ts`。
- `seekAndWaitForFrame` 等待实际目标帧；连续寻址以序号取消旧请求，调用方忽略 AbortError。SVG/粒子状态由时间确定，不累加上帧位置。
- 场景使用 Shadow DOM 和专用视频样式；工作台通过同源 iframe 的显式 `animationBridge` 操作 Player，不注入 CSS、不点击隐藏控件。
- 稳定逻辑 ID 可以跨镜头对应多个实例。当前可见几何的归一化 bbox 取可见实例联合边界，隐藏或未知返回 null。文字沿用原 timed_text ID。
- 工作台轨道来自真实脚本、clips、对象与文字时间。胶囊携带精确 Manifest 版本、render_element/clip/time_range 锚点；界面显示语义名称，内部 ID 仅负责引用。
- 选择框位于视频外层、pointer-events:none，随实际内容矩形缩放；导出使用纯 `/animation-render.html`，没有工具栏、选择框或调试 HUD。
- 发布经过公共契约校验、实际浏览器关键帧/anchor/文字可定位检查，再以 ProjectState CAS 替换当前引用。资源按内容摘要寻址且不可覆盖，检查回执绑定 bundle 摘要。
- 局部修订只传目标场景与必要上下文，保留对象 ID、脚本事实和时刻；未受影响资源复用。PN 支持确定性速度修改及模型调整受限视觉参数；VectorScene 支持模型重写目标场景。上游意见另存 RevisionRequest，尚不自动重跑知识/脚本层。
- 当前接口仅用于单机开发，端点与错误/恢复语义见 `docs/work/contracts/API.md`。启动导出前要构建当前前端；本地应用依赖匹配的源码与 dist。
