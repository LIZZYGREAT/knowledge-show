# 首次出片尝试（2026-11-14 凌晨）

## 目的

验证「知识包 → 脚本 → 动画」链路能否在比赛时限内出片。只验证链路与速度，不追求视觉质量。

## 做了什么

- 用脚本层提示词 v0.2 跑三个试点方向：骰子概率、PN 结、比喻/拟人/通感。
- 用独立校验器检查场景结构、时间覆盖、锚点、知识引用与依赖顺序。
- 选 PN 结按少字规则重跑一版，再让子 agent 按脚本制作 S01–S02 动画。

## 结果

- 三个方向都能产出合法的 ProductionScript。骰子、修辞通过校验；PN 第一版有 4 处知识依赖顺序错误（hook 抢跑尚未解释的概念）。
- PN 少字版：7 场、25 个事件、2 个锚点、5 条字幕共 40 字，字幕占屏约 6%。
- 动画：S01–S02（0–43s）单文件 Canvas 实现，约 5 分钟完成，场景边界与锚点跟脚本一致。

## 发现

- 链路可行，生成速度不是瓶颈。
- 没有视觉语言约束时，动画默认变成霓虹点阵：画面不解释，删掉字之后观众看不懂。
- 元素首次出现没有指认是硬伤，红蓝胶囊和粒子直接飘过去，不知道是什么。
- 脚本层能约束结构，约束不了画面语义；动画层需要自己的视觉语言和可复用部件。

## 已回写的规则

- 脚本提示词 v0.3：每个元素第一次出现必须指认身份，交代过之后才适用删字测试。

## 下一步

- 先定视觉风格，再做一小组可拼装部件：材料块、粒子、坡、引线、标注。
- 用 S01–S02 按部件重搭一遍，作为动画层样板。
