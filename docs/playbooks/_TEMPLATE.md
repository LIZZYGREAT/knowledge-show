# [操作名称：动词 + 对象]

> 用途：教 Codex **重复完成某一具体操作**。这是按需调用的操作手册，不属于所有任务的必读规则。文件名建议 `docs/playbooks/<动作>-<对象>.md`。

## 适用场景与交付物

- 何时使用：哪些任务需要运行本流程；什么情况不需要。
- 最终交付：应生成什么文件、报告或可验证结果（写清保存位置）。

## 前置条件

- 需要的工具/服务、现有项目状态、已知输入（例如页面 URL、端口、账号权限）。
- 首先检查是否已经具备条件；缺少工具时优先利用现有环境，不得未经授权大规模安装依赖或改变公共配置。

## 执行步骤

1. **准备**：实际执行的命令或操作，以及成功后的可观察状态。
2. **执行**：按真实顺序说明输入如何经过操作得到输出；命令、参数写成可替换形式。
3. **检查**：明确检查哪些内容、如何判定成功，以及常见失败时如何排查。
4. **整理**：保存必要产物，删除无价值临时文件；不破坏原有数据。

## 验收与报告

- 成功标准：哪些现象或文件可以证明本流程完成。
- 失败处理：无法执行时说明阻塞、已经完成的操作和未验证部分；不要编造结果。
- 交付说明：执行内容、证据位置、发现的问题、必要的后续动作。

> 不在本模板中复制通用代码规范、Git 规范或项目架构。只记录这一操作真正不同于其他任务的步骤。
