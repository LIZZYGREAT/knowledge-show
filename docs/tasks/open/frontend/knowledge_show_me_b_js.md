# Knowledge.Show(me) 长视频宣传片：视觉需求与 JS 动画实现设计方案

- **目标平台**：Bilibili（B 站）中长视频首发
- **成片规格**：`$1920 \times 1080$`（16:9 横屏），`$60\text{ fps}$`，时长建议 **2 分 45 秒（`$165\text{ s}$`）**
- **实现路线**：基于 Web/JavaScript（Canvas 2D + SVG/DOM 混合层）确定性时间轴程序化渲染，经无头浏览器逐帧采样后由 FFmpeg 合并音频导出高清 MP4
- **核心设计命题**：以 **「暖纸刊物与动态手工坊」** 为一脉相承的美学底座，以源自品牌标识的 **「棱片（The Prism-Fold）」** 作为贯穿全片的视觉主角，通过 **「白光经过棱镜，为何散出彩虹？」** 串联完整创作理念，并将 **真实可编辑工作台（局部定向修订）** 打造成全片高潮。

## 一、 美学定位与视觉边界

### 1.1 风格正本清源
本片必须与 Knowledge.Show(me) 前端页面（`theme.css`、`EditorialOrnament`、`LivingFlowScene`、`GraduatedStageBar` 及 `paper-editorial` 风格体系）一脉相承，确立独特且具高辨识度的 **Warm Editorial Craft & Living Motion Studio（暖纸刊物与动态手工坊）** 气质：

* **空间隐喻**：全片不存在“网页跳转到网页”的切屏感，所有场景均发生在**同一张被午后阳光照亮的无限暖白画桌 / 纸页平面**上。镜头通过推、拉、平移、掀角、翻页，在微观知识剧场与真实前端工作台之间连续穿梭。
* **视觉红线（严格规避）**：
  * **拒绝 AI 科技风**：禁用深黑/暗蓝科幻底色、霓虹发光描边、全息透视网格、赛博故障风、无意义发光粒子爆炸、电子电路线条。
  * **拒绝传统科普风**：禁用黑板粉笔、讲义卡片、大段公式堆砌、机械化 `01 / 02 / 03` 功能章节大字报、PPT 式卡片滑入淡出。
  * **拒绝低质互动收尾**：片尾不放“点赞投币收藏/评论区留言”等破坏刊物高级感的口播或弹窗，以克制留白的品牌标识收束落幕。

### 1.3 材质与触感规范（Canvas 2D 程序化实现）
1. **全局纸纹微噪点层（Paper Grain Layer）**：在最顶层叠加一张离线生成的无缝灰度纤维纹理（`$256 \times 256$` 周期平铺），混合模式为 `multiply`，不透明度控制在 `$0.028 \sim 0.04$`。为避免 MP4 压缩产生闪烁噪点，纹理坐标**锁定在世界空间**，仅随大幅镜头推拉轻微移动，严禁逐帧随机刷新。
2. **硫酸纸半透明叠色（Vellum Translucency）**：核心对象「棱片」与色散光带采用 `globalCompositeOperation = 'multiply'` 或半透明填充（`$\alpha \in [0.78, 0.90]$`），使交叠处自然透出底层纸纹与水彩叠印感。
3. **柔和彩色物理投影**：不使用纯黑生硬阴影，投影采用低饱和青灰或对应色相微偏移（如 `rgba(28, 52, 58, 0.10)`，`blur: 18px`，`offsetY: 8px`），强化阳光斜照书桌的真实景深。
4. **字体与刊物饰纹**：
   * 主标题与关键观念词：**典雅衬线体**（如 `Noto Serif SC` / 思源宋体 Medium–SemiBold），字距宽松（`$0.04\text{em} \sim 0.08\text{em}$`）。
   * 界面与辅助说明：**现代无衬线体**（`Noto Sans SC` / `Inter`）。
   * 数值、刻度与版本号（`v1` / `v2`）：**等宽数字字体**（`JetBrains Mono` / `tabular-nums`）。

## 二、 核心视觉对象设计：「棱片」（The Prism-Fold）

「棱片」不是外挂卡通吉祥物，而是 **Knowledge.Show(me) Brand Logo 右侧多面菱形棱晶的物理活化形态**，承担着 **好奇心化身、创作者手指隐喻、场景缝合媒介** 三重职责。

### 2.1 几何解剖与数据结构
在局部坐标系中，「棱片」由三个独立可驱动的子部件构成，基准外接尺寸设为 `$R = 36\text{ px}$`（随镜头缩放自适应）：

1. **上翼片（`upperFacet`）**：圆角等腰三角形，顶点朝上，材质为半透明硫酸纸青绿渐变（`#17A79F` 至 `#0E7C7B`），内边缘带 `$1\text{ px}$` 暖白高光线。
2. **下翼片（`lowerFacet`）**：圆角等腰三角形，顶点朝下，材质为半透明湖蓝渐变（`#5B8BF7` 至 `#3D63D8`），与上翼片交叠处呈现深青蓝叠印。
3. **暖杏光核（`amberCore`）**：位于上下翼片拼合中缝处的微缩菱形/柔光点（`#F2994A`），仅在“灵感触发、棱镜色散、修订生效、Logo 归位”四个高光时刻温柔点亮。
4. **伴生游丝（`trailingRibbons`）**：沿「棱片」运动轨迹自然拖曳出的 `$2 \sim 3$` 股细密三阶贝塞尔游丝（青绿、湖蓝、暖杏），复刻首页 `LivingFlowScene` 的流动感；当游丝被拉直并生长出短竖刻度，即无缝转化为 `GraduatedStageBar` 刻度标尺。

### 2.2 四种语义形态与状态机定义

在 JS 实现中，「棱片」应封装为独立的连续参数状态机，通过插值驱动四种核心形态的丝滑过渡（绝不生硬切图）：

| 状态枚举（`mode`） | 几何变换规则 | 物理隐喻 | 触发场景与产品映射 |
| :--- | :--- | :--- | :--- |
| **`GLIDE`（游走态）** | 上下翼片沿中轴微错位（`$\Delta y = \pm 4\text{ px}$`），翼角随速度矢量动态偏航与呼吸微摆（`$\pm 6^\circ$`），尾部牵引细游丝 | 两片轻盈贴合的折纸翅在纸面滑行、轻敲、探头 | 激发好奇、掀开纸角、引导观众视线在页面间移动 |
| **`PRISM`（棱镜态）** | 上下翼片严丝合缝闭合（`$\Delta y = 0$`），形成对称圆角菱形，中缝 `amberCore` 亮起，边缘浮现柔和玻璃折射高光 | 立在书桌上的实体棱镜，接收混沌白光并清晰色散 | 知识探索、拆解问题机制、呈现彩虹核心动画 |
| **`FOLD`（翻页态）** | 整体按中轴竖向放大至画幅高度，沿竖轴执行 `$[0, \pi]$` 的透视压缩翻折（`$\cos(\theta)$` 缩放 + 动态页背阴影），同步驱动 Canvas `clip()` 遮罩扫屏 | 翻动独立杂志的厚实色卡或立体书折页 | 动画阶段演进、同主题四风格无缝切换、跨主题转场 |
| **`BRACKET`（夹持态）** | **上下翼片彻底拆离**，先裂变为 2 组折角、再舒展为 4 枚精致的 **L 形对角选框角标**，精准扣合目标元素的包围盒（Bounding Box），四边连以极细虚线 | 创作者双手精准“框住”局部元素进行显微级精修 | **核心卖点**：真实工作台 `Workbench` + `selectionModel` 局部定向修订 |

### 2.3 运动性格与缓动规范
* **性格关键词**：灵动、克制、有纸张惯性与轻盈弹性（禁止迟钝线性匀速，也禁止过度 Q 弹的卡通果冻感）。
* **核心缓动函数**：
  * **位移与展开**：柔和强减速三次贝塞尔 `cubic-bezier(0.22, 1, 0.36, 1)`。
  * **掀角、点击与选框咬合**：轻微过冲的阻尼弹簧模型，其微分方程近似满足：
    $$\ddot{x} + 2 \zeta \omega_0 \dot{x} + \omega_0^2 (x - x_{\text{target}}) = 0$$
    推荐参数：阻尼比 `$\zeta = 0.78$`，自然角频率 `$\omega_0 = 18\text{ rad/s}$`（干脆利落，仅微过冲一次即稳稳落定）。
  * **翻页与扫尺**：对称优雅的正弦/四次缓入缓出 `cubic-bezier(0.65, 0, 0.35, 1)`。

## 三、 主案例视觉破题：暖纸上的「阳光棱镜与彩虹」

为彻底告别旧片“黑底实验室光学图”的科普课件感，主案例「白光经过棱镜，为何散出彩虹？」采用 **阳光书桌纸面光学** 视觉方案：

1. **入射白光（Sunbeam on Paper）**：一道柔和的 `$18^\circ$` 倾斜暖白光束从画布左上角掠过纸面，光束内带有极克制的柔和金白光带与微尘质感，射入竖立在暖白纸面上的半透明立体磨砂棱镜。
2. **纸面水彩波动丝带（Wave-Ribbon Dispersion）**：
   * 穿过棱镜的 7 道色光不使用死板的直线条，而是每道色光由 `$3$` 股极细的半透明波动曲线束组成。
   * 在 JS 中按真实物理直观建模波长 `$\lambda_i$`、相速度 `$v_i$` 与偏折角 `$\theta_i$` 的对应关系，沿各自折射方向 `$s$` 实时计算横波位移 `$n(s, t)$`：
     $$n_i(s, t) = A_i(s) \sin\left(\frac{2\pi}{\lambda_i} s - \omega_i t + \phi_i\right)$$
     * **珊瑚红（长波）**：`$\lambda$` 最长、振幅舒展、穿过棱镜边界时偏折角最小、行进姿态从容平缓。
     * **烟紫（短波）**：`$\lambda$` 最短、波峰紧凑灵动、穿过边界时减速最明显、偏折角最大。
   * 观众无需阅读任何折射率公式，单凭 7 股彩带在玻璃边界处“步幅不同、转弯角度自然拉开”的动态过程，即可瞬间获得纯粹的直觉顿悟。

### 4.2 逐幕深度分镜与动画逻辑设计

#### 第一幕：破纸而出与悬念反转（`0:00 – 0:22`）
* **`0:00 – 0:06`｜极致的静与枯燥**
  * **画面**：镜头微距俯拍一张平铺的暖米白纸页，版式如传统讲义：左侧印着呆板的灰度文字“光的色散：复色光通过三棱镜分解为单色光……”，右侧是一枚毫无生气的灰色细线三角形。
  * **音效**：安静的纸面微风与轻微翻纸摩擦声。
* **`0:06 – 0:14`｜立体书式苏醒**
  * **画面**：句号轻轻一颤，「棱片」（`GLIDE`）从纸缝探角滑出，先绕着灰色三角形好奇地轻碰两下，随即一角钻入底边猛地向上撬起——纸面如立体书（Pop-up Book）般轰然折叠撑起，灰三角立成一座半透明磨砂三棱镜！一道午后暖白斜光掠过纸面撞击棱镜，七股水彩波动丝带瞬间铺展绽放。
  * **音效**：清脆的折纸弹起声、温润玻璃轻叩声，随后温暖轻快的马林巴与木吉他主旋律精准入拍。
* **`0:14 – 0:22`｜反套路留存钩子（核心反转）**
  * **画面**：音乐突然轻巧停顿半拍，彩虹画面微定格。「棱片」从棱镜旁飞到前景，迅速切入 **`BRACKET` 微形态**——直接伸手捏住彩虹最下方的紫光波动丝带，轻轻往回一拨。紫光波峰瞬间肉眼可见地变紧、角度小幅微调，旁侧手绘铅笔标注随之灵动跳变，而其余六道色光丝毫未受干扰。
  * **文案/旁白**：*“把一个问题变成动画，已经不稀奇了；但如果动画里的每一个念头，你都能伸手去拨动呢？”*
  * **衔接机关 ①**：棱片松手合拢，整道彩虹顺着惯性倒卷回棱镜，凝聚为一根细长的暖白光线，轻巧落平在画布中央，化作微微闪烁的**输入光标**。

#### 第二幕：提问生光与故事骨架（`0:22 – 0:52`）
* **`0:22 – 0:30`｜真实创作入口**
  * **画面**：闪烁光标周围柔和浮现真实前端创作页 **`CreationComposer`** 的暖纸轮廓（完全忠于真实页面结构与按钮样式）。问题逐字键入：**「白光经过棱镜，为何散出彩虹？」**，真实创作模式选项依次轻滑并选中「直观演示」。「棱片」落于确认按钮上轻点一下。
* **`0:30 – 0:42`｜字面意义的“光学拆解”（知识探索与事实核验）**
  * **画面**：按钮被点下的瞬间，镜头顺着文字潜入纸页深层；真实表单柔和隐退，**「棱片」于画面正中严丝合缝闭合为 `PRISM` 棱镜态**。整句提问化作一束文字白光射入棱片，穿过后如真正色散一般，清晰展开为 **3 股带有柔和色泽的知识线索丝带**（伴随极克制的关键词纸签）：

## 六、 JS 程序化动画实现与 MP4 导出工程规范

针对“使用 JS 实现动画，最终导出合并为 MP4”的技术路线，本方案沿用并升级项目现有 `promo/` 目录的离线渲染管线，确保 `$60\text{ fps}$` 绝对零掉帧、零闪烁、音画毫秒级同步。

### 6.1 核心原则：确定性时间驱动（Deterministic Time-Stepping）
严禁使用依赖系统时钟的 `requestAnimationFrame(now)` 或不可控的 `Math.random()` 与 CSS `transition` 来驱动成片状态：

* **全局统一时钟入口**：所有动画与 UI 状态均由单一纯函数 `window.__renderFrame(frameIndex, fps)` 驱动，通过 `$t = \text{frameIndex} / \text{fps}$` 精确计算当前秒数，支持任意帧随机跳转（Seek）与多进程分段并发渲染。
* **确定性随机数（Seeded PRNG）**：所有纸纹、波束相位偏移、微粒飘动均使用固定种子的伪随机数生成器（如 Mulberry32），确保反复导出结果逐像素一致。
* **时间线分段解耦**：建立集中式时间表 `timeline.js`，每幕接收归一化局部进度 `$u \in [0, 1]$` 与局部秒数 `$t_{\text{local}}$`，方便独立精调某一幕节奏而不破坏全局衔接。

### 6.2 推荐模块化目录架构（升级 `promo/`）

### 6.3 三层混合渲染架构（解决 Canvas 动画与真实 DOM 融合）

为了同时实现**丝滑的 Canvas 光学/纸艺动画**与**100% 真实的 HTML/CSS 前端工作台**，舞台容器（`$1920 \times 1080$`，关闭滚动条）采用严格的三层叠放结构：

1. **Layer 1（底层 Canvas `#stage-world`）**：绘制暖白纸底、环境光晕、立体书折页、彩虹波列、跨主题动画以及故事弧线。
2. **Layer 2（中层 DOM `#stage-ui`）**：挂载剥离冗余壳层的真实前端视图组件（`CreationComposer`、`GraduatedStageBar`、`Workbench`）。在 `renderFrame(t)` 中通过纯 JS 同步更新其 CSS `transform`（与 `camera.js` 共享同一变换矩阵）、打字机文本长度、真实时间轴游标与 `v1/v2` 状态，**禁止开启任何 CSS `transition` 过渡**，完全由逐帧数学插值控制。
3. **Layer 3（顶层 Canvas `#stage-overlay`）**：绘制始终凌驾于页面之上的「棱片」主角、`BRACKET` 对角选框、框内暖杏水墨涟漪、描图纸对比竖线、扫屏标尺，以及全局锁定的微纸纹 `multiply` 滤镜层。

### 6.4 音频同步与 FFmpeg 高清导出管线

1. **离屏音频精准对齐**：
   * 依托 `timeline.js` 中的同一份事件时间戳（如 `0:06.2` 掀纸、`0:14.5` 捏住紫光、`1:52.0` 选框涟漪爆发、`2:20.4` 标尺扫屏），通过 `OfflineAudioContext`（`$48\text{ kHz}$` 立体声）程序化渲染或混音导出完整无损 `promo-audio.wav`，确保每一个纸张翻折声、木琴重音与画面事件误差为 `$0\text{ ms}$`。
2. **无头浏览器逐帧采集（`render.mjs`）**：
   * 启动 Playwright Chromium，设定视口 `$1920 \times 1080$`，`deviceScaleFactor: 1`（或 `2` 后下采样以获得超清矢量抗锯齿），等待所有字体（`document.fonts.ready`）与纹理加载完成。
   * 循环遍历 `$f = 0 \dots 9899$`（`$165\text{ s} \times 60\text{ fps}$`），调用 `await page.evaluate(f => window.__renderFrame(f, 60), f)`，将 `page.screenshot({ type: 'png' })` 直接通过 Node.js `stdin` 流式管道喂给 FFmpeg，避免磁盘写入近万张临时 PNG 导致的 I/O 瓶颈。
3. **FFmpeg B 站高码率压制参数参考**：

```bash
ffmpeg -y \
  -f image2pipe -vcodec png -framerate 60 -i - \
  -i ./output/promo-audio.wav \
  -c:v libx264 -preset slow -profile:v high -level 4.2 \
  -crf 15 -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 320k -ar 48000 \
  ./output/knowledge-show-promo-v2.mp4
```

> **画质保护要点**：暖白纸面叠加淡彩渐变极易在低码率压制下出现色彩断层（Color Banding）。上述全局微纸纹滤镜本身就能起到天然的抖动防断层（Dithering）作用，配合 `-crf 15` 与 `yuv420p` 可确保在 B 站二压后依然保持通透干净的刊物纸感。
