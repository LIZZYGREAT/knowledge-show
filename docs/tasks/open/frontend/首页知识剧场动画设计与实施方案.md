# Knowledge.show(me) 首页知识剧场动画设计与实施方案

> **任务类型**：首页视觉设计 / 核心动画重构 / 小范围前端实现  
> **仓库基线**：`LIZZYGREAT/knowledge-show`，`main@698459fc045ba2c3957b546744c2ca53cea6bfd9`  
> **建议存放位置**：`docs/tasks/open/frontend/首页知识剧场动画设计与实施方案.md`  
> **本轮目标**：仅优化首页的主视觉及其配套文案、布局和动效，让用户在几秒钟内感知这是一个能够把知识变成精彩动画的视频创作工具。**不调整知识/脚本/动画生产层，不重构工作台和已确认的创作表单。**

## 一、现状与设计判断

当前首页 `LandingHero.tsx` 的主体是左侧标题“让知识，动起来。”和右侧 `LivingFlowScene`。`LivingFlowScene.tsx`、`flowGeometry.ts` 已实现连续曲面、丝线、光泽和粒子共用一个运动几何场，动画相当精致；`useFlowMotion.ts` 已处理页面不可见、失焦、移动端与减少动画偏好。

问题主要是**表达对象与产品不够紧密**。绿色流体本身足以用在创意工作室、AI 产品、数字艺术等网站，单靠文案无法让第一次看到页面的人知道：这里能生成“具体、有趣、可看懂的知识视频”。

这次应当保留现有优点：

- 柔和的米白 / 深绿 / 香槟金品牌气质、衬线大标题和适度的植物线条装饰。
- 现有丝带的流动曲线、局部金色高光和连续运动，不要粗暴替换成普通方框流程图。
- 首屏布局以“标题—开始创作—核心动画”为主，不增加冗长产品说明、技术术语和复杂选项。

需要调整的是**动画承担什么叙事**，而非仅更换丝带颜色、播放速度或放一层纯装饰粒子。首页必须出现可辨认的知识对象，并通过运动真正表现一个小知识点。

## 二、确定方案：好奇心的微型知识剧场

### 1. 核心概念

**一颗好奇心的种子，在画面中引出一段会运动的知识。**

右侧保留流体的柔美轨迹，但它不再始终占据舞台中央；它成为连接“问题”与“知识对象”的引导线。观众看到的最终焦点是一座精致、轻巧、具有真实空间层次的**知识小剧场**，其中的对象连续变化，演示一个有趣而准确的现象。

与传统视频播放卡片不同，首页舞台本身是页面原生的 SVG/HTML 动画，有纸面、透明材质、细线、光点与具体运动对象。它可以在自然的品牌布局中“发生”，而不是硬塞进巨大的播放器矩形。无需制作伪视频控制条，更不用嵌入复杂工作台 UI。

**视觉关键词**：编辑纸张、细线装置、精细光点、可辨认的对象、柔和景深、连续物理变化、清晰的视觉焦点。

### 2. 推荐示例主题：为什么两个骰子的点数和为 7 最常见？

只用**一个 10 秒左右的小知识演示**，不在首页轮播三个不同主题。选择骰子概率作为首页专属的定制动画，是因为：

- 两个骰子是普通用户无需学习术语就能认出的对象。
- 骰子的点数、组合、数量分布可以被真实视觉动作串联，符合产品“把知识做成动画”的核心卖点。
- 既能做出轻巧的纸艺美术，又容易兼容现有绿色/米白品牌色。
- 数学关系明确：两个公平六面骰子有 36 个有序结果，和为 7 的有 6 个，最多。适合以简洁字幕辅助说明。

**注意**：这是**首页品牌专用演示**，不是“概率主题必须用骰子”的生成模板，更不是对脚本层和动画层加入新的知识限制。后续有更好的真实成片时可以更换首页演示主题，仍遵守相同的“知识对象—连续变化—结论出现”的设计逻辑。

### 3. 页面大构图

保持目前的桌面端左右关系，建议从现有约 `43% / 57%` 微调为更利于展示视觉主体的比例（可先维持原值试做，再依据截图调整）：

这只是信息和视觉重心示意，实际舞台不应制作成黑色实线卡片。舞台应通过淡纸面、悬浮纸层、轻微阴影和外围丝带自然形成空间边界。

**第一帧就应漂亮而完整**：两枚实体感骰子、局部概率纸盘/示意线条在页面出现时已经可辨认，动画随后使它们发生变化。不要等待 5 秒的光点汇聚后，用户才看到真正的内容。

## 三、核心动画的连续演出设计

建议一个约 **9–11 秒**的自然循环，不要求精准卡秒；以相对阶段控制，观感为准。动画不是四页 PPT 的交替切换，而是一组对象**始终在场、持续发生状态变化**。

### 1. 初始画面（0–1.5 秒）：问题已可见

右侧是一个悬浮的、略带角度的纸面实验台。画面中心已存在两枚细致的骰子：柔和纸/磨砂质感，能看出点数和体积。淡绿色流体丝带穿过实验台外围，形成流向知识核心的曲线，少量金色光点沿路径移动。微标题“为什么 7 最常见？”以高可读的短文字出现。

**视觉中心**首先是骰子，而不是大面积花纹或光带。左右间距要足够，让标题与 CTA 不受到光效侵扰。

### 2. 直觉形成（1.5–3.5 秒）：两个骰子轻盈滚动

骰子沿小幅弧线旋转、落定，最终出现例如 3 和 4 的点数。点数周围短暂出现一束细线，落点显示“3 + 4 = 7”。这是一个具体的、能直接看懂的变化，不要大段解释。

动作质感偏纸艺机械小装置：轻、柔、有惯性；运动不要像随机粒子抖动，也不需要真实 3D 物理引擎。可以用 SVG 形变与遮挡层次表现轻微厚度。

### 3. 结构展开（3.5–6.8 秒）：组合在同一画面中生长

骰子的点数沿现有细线“复制”出小点，逐步排列为一个精致的 6×6 组合点阵（36 个可能结果）。不是一次闪出一个表格：点沿曲线迁移、分列、落位，观察者能够看出“组合逐渐增多”。

其中对应和为 7 的 **6 组有序组合**依次被金色细线穿过或圈亮，其余组合降低对比。只有必要的提示文字“36 种组合，其中 6 种相加为 7”。点阵占据中央主要面积，骰子缩小移至侧边作为来源物，不要同时出现两个一样大的焦点。

### 4. 得到结果（6.8–8.8 秒）：高亮汇聚为结论

高亮的六个点沿弧形轨迹向中央汇聚，带出一个轻巧的 **7** 和简洁的数量差异图形（可以是由点的数量堆叠形成的三角轮廓，不必另建完整柱状图）。让用户直接体会：7 的组合数比其他点数和多。

这是整个循环最具有记忆点的一瞬间。颜色、运动、声量感（即使无声音）都可以略微强化，但不能用刺眼闪白、过强晃动或全屏粒子爆炸来抢注意力。

### 5. 轻柔回环（8.8–10.5 秒）：对象重新收拢

点阵沿路径回到两枚骰子与纸面实验台，短文字淡出，丝带仍保持非常轻微的流动，回到初始构图。**不黑屏、不整场淡出再硬切重播**，第一帧与最后一帧需要几乎无跳变。

循环可以留 0.5–1 秒视觉驻留，让用户有时间看清画面，不追求一直高频运动。

### 6. 避免“PPT 式”的明确约束

- 不使用“知识层→脚本层→动画层”三个巨大文字面板做主动画。
- 不用纯文本弹窗、进度步骤和箭头来代替知识对象的动作。
- 不让骰子、点阵、结论三个完整屏幕互相硬切。它们应当通过对象的运动和形态延续发生联系。
- 不要求每个知识元素都可交互；首页是品牌展示，不应做成需要鼠标操作才能看懂的游戏。
- 不靠添加几十个无意义光点制造“高级感”。装饰服从主对象。

## 四、视觉语言：与网页品牌相配，但不绑定视频风格

### 色彩与材质

沿用网站当前已有色彩：米白基底 `--ks-canvas`、深绿色 `--ks-accent-strong`、金色 `--ks-warm`。首页演示的主色可使用浅纸色、低饱和绿色、烟灰蓝及少量暖金；对比应集中在骰子与正确组合上。

推荐画面层级：

1. **背景**：与网页自然融合的暖白底，轻微纹理或柔和渐变，不铺满深色底板。
2. **舞台**：有厚度和微妙阴影的纸片/透明小装置，形成层次。
3. **知识主对象**：骰子、点阵、高亮轨迹，边缘清楚，颜色区分明确。
4. **引导装饰**：现有绿色丝带的部分曲线、纤细金线、少量光点，只负责连贯和导视。
5. **文字**：微标题和极短的知识提示，字号不得小到无法阅读；避免用全英文标注实质内容。

应避免把右侧画面做成复杂 UI 截图、伪编辑器或大视频播放器。首页主要卖点是“有趣的知识动画作品”，编辑器能力留给后续内容或一个轻量提示即可。

### 运动特征

视觉应像一个精心制作的微型动态艺术装置：同一对象有连续身份，运动包含起势、加速、到位、短暂停留和回环。不要帧切换动画；不要每隔一秒出现一组孤立图案。

建议：主对象 2–3 层视差、纸面轻微阴影、细线同步生长，运动轨迹使用平滑曲线。静止的时间也有轻微生命感，但不能全体对象永远漂浮。避免让页面滚动或鼠标移动成为观看主线的必备条件。

## 五、文案与内容组织

保留主标题 **“让知识，动起来。”**，它简洁、准确，值得继续使用。配套副标题建议比当前的“把好奇变成一支值得看完的动画”更明确产品：

> **把一个好奇的问题，变成一支值得看完的知识动画。**

保留 `开始创作` 作为唯一明显的主 CTA；不增加多个同等级按钮。原文“只要一个想法，剩下的交给我们。”可以保留。

右侧微型剧场可有一个很轻的知识标题“为什么 7 最常见？”，但不要在画面上下额外堆满研究、脚本、动画三个工程步骤的介绍。

页面底部已有“知识探索 · 脚本编排 · 动画制作”，这足以承担对三层流程的轻量解释。用户无需在首页学习后台是如何工作的。

## 六、实现方案：沿用现有代码，局部重构

### 1. 推荐修改范围

| 文件 | 处理方式 | 具体任务 |
| --- | --- | --- |
| `frontend/src/features/landing/LandingHero.tsx` | 小幅调整 | 保留标题、CTA 和整体布局，右侧从单纯 `LivingFlowScene` 调整为知识剧场动画，替换一句副标题 |
| `frontend/src/features/landing/LivingFlowScene.tsx` | **部分保留/拆用** | 保留有价值的流体光带/光点作为舞台外围导视，不要复制整套复杂几何作为主舞台 |

| `frontend/src/features/landing/CuriosityStage.tsx` | 建议新增 | 右侧的纸艺知识剧场：骰子、组合点阵、结论的连续视觉对象 |

| `frontend/src/features/landing/curiosityMotion.ts` | 可选新增 | 仅当关键状态计算复杂时抽离 10 秒时间轴；不要为了模块化拆出许多空文件 |
| `frontend/src/common/theme.css` | 仅局部修改 | 调整首页网格间距和移动端适配；不重做全站色彩或其他页面 |
| `frontend/tests/e2e/creation.spec.ts` 或现有首页测试 | 小范围补测试 | 页面主 CTA、动画存在、移动端与减少动画等基本验收 |

不修改：`backend/src/knowledge/`、`backend/src/script/`、`backend/src/animation/`、`contracts/schemas/`、工作台时间轴、视频四套 Style Profile、API、生产任务状态。**首页特效与最终成片风格应当完全解耦。**

### 2. 运动实现建议

- 使用现有 React + SVG + 轻量 CSS；现有 `useFlowMotion` 已有约 30 FPS 的可见性调度，优先复用。首页无需新增重型 3D 框架。
- 统一使用**一个时间源**生成骰子滚动、丝带伸展、点阵生长和结论聚合的状态；不要为每种元素各自启动不相关的循环动画。
- 静态 SVG 元素尽量固定 DOM/React 结构；变化主要更新 transform、opacity、path 等属性。当前 `flowMesh` 生成大量曲线路径，避免整个高密度网格在新舞台稳定后仍高频全量重算。必要时降低其装饰层采样或让它转为静止背景。
- SVG 保留视图框坐标与画面比例自适应；所有文字使用合适的浏览器中文字体回退，避免罕见字体导致错位。
- `prefers-reduced-motion` 时直接显示**完整的高质量静态结论画面**，用户无需等待入场动画。
- 标签页隐藏、元素不可见、窗口失焦时暂停；页面回来后平滑恢复，不突然追赶大量帧。
- 不请求外网图片、模型 API 或视频生成服务完成首页动画。核心展示应离线可运行、首次加载即可出现。

### 3. 逐步交付方式

**P0 — 单屏视觉静态样稿**：先把右侧舞台的静态最终构图做精细。要求骰子、组合点阵、纸层、金色高亮、丝带的相互关系在不播放时就好看，且让人看出“这是知识动画”。这一步完成后直接截图检查，再继续运动。

**P1 — 贯通一条连续动画**：用一个全局时间进度打通五个阶段；保证知识对象在运动中始终有身份，第一帧不空，循环不突兀。无需增加额外风格切换器或人工操作。

**P2 — 网页整合与响应式**：只调整首页右侧主视觉的大小、位置与文本；至少在 1440×900、1280×720 两种桌面宽高及 390px 左右移动端检查。移动端舞台可简化粒子和细节，但保留骰子→组合→高亮的可理解主线。

**P3 — 验收后提交**：检查页面滚动、CTA、样式溢出、帧率及运动偏好。对照截图验收，与已有首页效果比较，确认“有趣的知识视频工具”识别度提升，而不是单纯更花哨。

## 七、验收标准与常见错误

### 必须满足

1. **三秒内懂产品方向**：第一眼能看到具体知识对象；主文案和视觉共同说明这是“知识变成动画”的产品，不依赖用户读完整说明。
2. **画面确实精致**：骰子立体感、细线、纸层、粒子、文字、阴影之间有明确层次；不只是放大当前丝带或给背景加渐变。
3. **主视觉中心明确**：重要对象足够大，在 1280 宽页面仍看得清；标题、按钮、核心对象不会互相覆盖。
4. **动画真实连续**：骰子→组合→结论之间有可跟随的状态变化；不能做成相互切换的三张插画。
5. **Loop 合理**：可自然重复播放，用户观看 10–20 秒不会遭遇明显闪断或全屏重置。
6. **用户不增加负担**：开始创作是主动作，首页演示无需用户点击开启或配置选项。
7. **性能合理**：普通笔记本浏览器能平滑运行；移动端降低绘制密度，标签页不可见时不持续消耗 CPU。
8. **可访问性**：装饰性 SVG 不读入屏幕阅读器；内容通过可见副标题和简短无障碍描述说明；减少动画模式有可读的静态画面。
9. **无功能回归**：创作按钮、设置入口、页面导航、表单页和现有业务请求仍正常。

### 需要防止

- 把首页做成科技公司常见的发光曲线、网格粒子和“AI 思考”动画，没有具体知识对象。
- 把三层工作流硬塞到巨大的节点流程图上，以工程概念取代视觉作品。
- 将首页配色统一套进视频生成四套 Style Profile，从而损害视频独立美术风格。
- 让丝带、骰子、矩阵、文字、粒子同时争当视觉焦点。
- 靠大量虚化、泛光、纹理掩盖对象造型不够精致的问题。
- 首屏起始只有一个光点，等待数秒才有画面，普通用户可能直接离开。
- 只实现桌面效果，移动端被裁掉关键对象或占据过大纵向空间。

## 八、执行与最终交付
